HTML 基础标签

网页的骨架

HTML 文档结构

<!DOCTYPE html> ← 声明类型

<html> ← 根标签

<head> ← 头部（不可见配置）

<body> ← 身体（页面显示的内容）

所有网页都是这个基本结构。就像一栋房子的地基和框架。

标题标签 h1~h6

<h1>一级标题</h1> 最大

<h2>二级标题</h2>

…

<h6>六级标题</h6> 最小

一个页面一般只有一个 h1（搜索引擎用它理解页面主题），h2-h6 用来分层。

段落和文本

<p>这是一个段落。</p>

<strong>加粗</strong> — 强调

<em>斜体</em> — 着重

<br> — 换行（单标签）

<hr> — 水平分割线

链接 a 标签

超链接是互联网的基础：

<a href="https://example.com">点我访问</a>

属性：

  • href — 链接地址
  • target="_blank" — 在新标签页打开
  • 可以链接到外部网站、内部页面、甚至是页面内的某个位置

图片 img 标签

<img src="图片地址" alt="描述文字">

  • src — 图片文件路径（支持相对/绝对/URL）
  • alt — 图片加载失败时显示的文字（也用于辅助阅读）
  • width / height — 可控制尺寸

列表 ul / ol

无序列表（圆点）：

<ul>

  <li>苹果</li>

  <li>香蕉</li>

</ul>

有序列表（数字）用 <ol>。

总结

  • HTML 由标签组成，成对出现
  • h1~h6 标题，p 段落，a 超链接，img 图片
  • ul/ol + li 做列表
  • 标签可以有属性（href、src、class 等）
