命令行入问/h1>
不用鼠标也能操控电脑

命令行是什么？

命令行（CMD）是 Windows 自带的文字交互工具。你看不到按钮和图标，只能输入命令，系统执行、/p>

打开方式！span class="key">Win + R ↀ输入 cmd ↀ回车

或者：在文件夹的地址栏输入cmd ↀ直接在该路径打开命令行/p>

为什么学命令行？有些操作没有图形界面，只能命令行。而且一个命令可以批量处理成百上千个文件、/div>

最常用的命代/h2>
  • dir —列出当前目录下的文件和文件夹
  • cd 文件夹名 —进入文件备/li>
  • cd .. —返回上级目录
  • mkdir 文件夹名 —新建文件备/li>
  • type 文件名/code> —显示文件内容（文本文件）
  • cls —清屏
  • exit —关闭命令行/li>

文件和目录操但/h2>
  • copy 源文代目标位置 —复制文件
  • move 源文代目标位置 —移动文件
  • del 文件名/code> —删除文件
  • ren 旧名 新名 —重命名/li>
  • tree —以树形显示目录结析/li>
在命令行的路径里！code>. 表示当前目录！code>.. 表示上一级目录、/div>

网络命令

  • ipconfig —查看本机 IP 配置
  • ping baidu.com —测试网络连通态/li>
  • nslookup baidu.com —查看域名的IP 地址
  • netstat -ano —查看所有网络连接和端口
  • tracert baidu.com —追踪数据包经过的路由
网络出问题时，先用ping 检查能不能通，再用 ipconfig 检查配置、/div>

系统信息命令

  • systeminfo —详细系统信息（OS 版本、内存、网卡）
  • tasklist —列出所有运行中的进程（PID！/li>
  • taskkill /PID 1234 —根据 PID 结束进程
  • sfc /scannow —扫描和修复系统文代/li>
  • shutdown /r /t 0 —立即重启

管道和重定向

命令行的强大在于组合！/p>

  • dir > list.txt —把目录列表输出到文件
  • tasklist | find "chrome" —只显示包名chrome 的进程/li>
  • ipconfig | find "IPv4" —只显示IPv4 地址
  • ping baidu.com >> log.txt —追加输出到文代/li>
> 是输出到文件（覆盖）！code>>> 是追加，| 是管道（把前一个命令的结果传给后一个）、/div>

总结

  • Win + R ↀcmd 打开命令行/li>
  • dir、code>cd、code>copy、code>del 管理文件
  • ipconfig、code>ping、code>netstat 排查网络
  • tasklist、code>taskkill 管理进程
  • > 输出到文件，| 管道传通/li>
  • 一个命令可以配合通配符批量操作，比如 del *.tmp 删所有临时文代/li>
