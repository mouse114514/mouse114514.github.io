响应式设计与媒体查询

一个页面适配所有屏幀/div>

什么是响应式？

同一个网页在手机、平板、电脑上都能正常显示，自动适配屏幕大小、/p>

  • 电脑一3 列布局 ↀ手机上变 1 分/li>
  • 大屏字体 18px ↀ小屏字体 14px
  • 导航栏菜单ↀ手机折叠为汉堡菜单/li>

viewport 设置

响应式的第一步：HTML 头部力viewport meta 标签、/p>

<meta name="viewport" content="width=device-width, initial-scale=1.0">

告诉浏览器按设备真实宽度渲染，不缩放页面、/p>

媒体查询 @media

针对不同屏幕宽度写不名CSS！/p>

.container { display: grid; grid-template-columns: 1fr 1fr 1fr; }

@media (max-width: 768px) {

  .container { grid-template-columns: 1fr; }

}

屏幕宽度 ≀768px 时变成单列、/p>

常见断点（Breakpoints！/h2>
  • ≀480px —小屏手机
  • 481px ~ 768px —平板竖屏
  • 769px ~ 1024px —平板横屏/小笔记本
  • ≀1025px —桌面

可以用min-width 戏max-width，通常用min-width 往上做、/p>

相对单位

响应式不用px 固定尺寸，用相对单位！/p>

  • % —百分比相对于父元紀/li>
  • vw / vh —视口安高的百分毀/li>
  • em —相对于父元素字体大小
  • rem —相对于根元素 (<html>) 字体大小
  • clamp() —范围值：font-size: clamp(14px, 3vw, 24px)

Flex/Grid 响应开/h2>

Flexbox 自动换行！/p>

.flex-container {

  display: flex;

  flex-wrap: wrap;

}

.flex-container > * { flex: 1 1 200px; }

每个子元素至就200px，空间够就多列，不够就换行、/p>

总结

  • 移动端优先设计（先写小屏样式，再 @media 放大！/li>
  • @media (min-width: 768px) 常见断点
  • 用%、vw、rem 代替 px 固定倀/li>
  • flex-wrap 实现自动换行布局
  • clamp() 让字体跟随视口自适应
