第二课

键盘与窗口焦点

你的按键到底去了哪里？

窗口焦点是什么？

你面前有多个窗口，但你打字时字只会出现在其中一个——那个就是焦点窗口。

焦点（Focus）是操作系统用来决定"键盘输入送给谁"的机制。任何时候，整个系统里有且只有一个窗口拥有焦点。

点击一个窗口 → 它拿到焦点，标题栏变亮 → 你的按键都发给它

标题栏变灰的窗口在"后台"，收不到键盘消息。

焦点丢失：你到底在往哪打字？

新手最常见的问题："我明明在打字，怎么字跑到别的地方去了？"

  • 你打开了记事本和浏览器，在记事本打字正常
  • 不小心点了一下浏览器 → 焦点转到浏览器
  • 继续敲键盘 → 字全进了浏览器的搜索框
用 Alt + Tab 切换窗口时，焦点跟着走。
核心：焦点的本质是"系统当前把键盘消息发送给哪个窗口句柄"。

焦点的背后：消息队列

Windows 是一个消息驱动的系统。你按下键盘 → 硬件中断 → 系统生成一个"按键消息" → 投递到焦点窗口的消息队列。

  • 每个窗口都有自己的消息队列（Message Queue）
  • 系统只把键盘消息发给拥有焦点的那个窗口
  • 程序不断从队列里取消息处理——这叫消息泵（Message Pump）
按键 → 系统消息队列 → 分发到焦点窗口的消息队列 → 程序取走处理

Z 序（Z-Order）

窗口在屏幕上不光有 X、Y（位置），还有Z 轴——即谁在上面、谁在下面。这叫做 Z 序。

  • 最上面的窗口叫顶层窗口（Top-Level）
  • 顶层窗口通常拥有焦点（但不一定！）
  • 被盖住的叫下层窗口
  • 把窗口"置顶"（TopMost）可以强制它一直在最前
Alt + Esc 可以强制把下一个窗口提到顶层，但不一定给焦点。

前台窗口 vs 焦点窗口

很多人以为"最前面的窗口"就是焦点窗口，其实不完全正确：

  • 前台窗口（Foreground Window）：Z 序最顶层的窗口
  • 焦点窗口（Focus Window）：实际收到键盘输入的窗口

一般情况下它俩是同一个，但也可以不同。

比如一个对话框弹出来，对话框是前台窗口，但它里面的文本框之间的焦点切换，不会影响主窗口。

快捷键的底层原理

快捷键（Accelerator / Hotkey）本质就是预注册的消息过滤器：

  • 系统投递键盘消息前，先检查有没有全局热键（如 Win+D）匹配
  • 匹配上了就直接消费掉，不再发给焦点窗口
  • 没匹配上才发给焦点窗口

Win+L 锁定系统 → 这是系统级热键，任何时刻都能抢走焦点。

总结

  • 焦点 = 系统决定"键盘输入给哪个窗口"的机制
  • 每个窗口有一个消息队列，消息驱动运行
  • Z 序决定窗口前后层次，前台窗口通常拥有焦点
  • 快捷键是系统层级的消息过滤器，优先级高于普通按键
  • 打字跑错地方 → 检查焦点在哪里
想知道当前焦点在哪个窗口？按 Alt + Tab 看高亮的那个就是。
