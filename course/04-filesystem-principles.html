第四课

文件系统原理

文件到底是怎么存在硬盘上的？

什么是文件系统？

文件系统是操作系统用来组织和管理硬盘数据的一套规则。你可以把它理解为"硬盘的目录索引系统"。

没有文件系统，硬盘就是一个巨大的字节数组，没办法知道哪段数据是哪个文件。

常见文件系统：Windows 用 NTFS，U盘常用 FAT32 / exFAT，Linux 用 ext4。

NTFS 核心结构

NTFS 把所有数据都视为"文件"。包括目录本身也是一个文件——$Root 文件。

  • MFT（主文件表）—— 文件系统的核心索引，每个文件在 MFT 中有一条记录
  • MFT 记录包含了文件的属性：文件名、大小、时间戳、数据位置
  • 小文件的数据可以直接存在 MFT 记录里（resident），不用额外分配空间
查看一个文件占用的实际扇区位置：用工具 fsutil 命令。

文件路径的本质

路径如 C:\Users\YourName\test.txt 不是简单的字符串，而是一条引用链：

  • 从根目录的 MFT 记录 $Root 开始
  • 查找目录项"Users" → 得到 Users 文件夹的 MFT 引用
  • 在 Users 文件夹中查找"YourName" → 得到其 MFT 引用
  • 最终找到 test.txt 的 MFT 记录

文件的实际存储

一个文件不是连续存放在硬盘上的！

  • NTFS 把文件数据分成 簇（Cluster，默认 4KB）
  • 文件可能分散在硬盘的不同位置——这叫碎片化
  • MFT 记录里有一个 $Data 属性，指向文件数据的簇列表
  • 大文件的 $Data 会分成多个 Extent（段）记录
"删除文件"并没有擦除数据，只是把 MFT 记录标记为"可用"。这也是为什么删除的文件能恢复。

NTFS 权限机制

NTFS 权限是基于 ACL（访问控制列表）的：

  • 每个文件/文件夹有一个 安全描述符（Security Descriptor）
  • 安全描述符包含 ACE（访问控制项）列表
  • 每条 ACE 规定了某个用户/组可以做或不能做什么
  • 权限类型：读取、写入、修改、完全控制
右键文件 → 属性 → 安全，就能看到这个文件的 ACL。

硬链接、软链接与快捷方式

  • 硬链接（Hard Link）— 同一个 MFT 记录有多个文件名，删一个不影响数据
  • 符号链接（Symlink）— 重定向到另一个路径，目标可以是远程共享
  • 快捷方式（.lnk）— 只是一个普通文件，里面存了目标路径
用 mklink 命令可以创建硬链接和符号链接。这是管理磁盘空间的强大工具。

总结

  • 文件系统 = 硬盘的索引系统，NTFS 是 Windows 的核心 FS
  • MFT 是 NTFS 的"总索引表"
  • 路径是一层层目录 MFT 引用的链式查找
  • 文件数据不连续存放，用簇列表定位
  • 删除文件只是标记 MFT 记录为"可用"
  • 权限通过 ACL/ACE 控制
  • 硬链接不复制数据，同一个 MFT 记录有多个名字
