JavaScript DOM 高级操作

动态创建、遍历与事件委托

创建和插入元素

用 JS 动态生成 HTML：

let li = document.createElement("li")

li.textContent = "新项目"

li.classList.add("active")

document.querySelector("ul").appendChild(li)

appendChild 在末尾添加，prepend 在开头添加。

删除和替换元素

element.remove() — 删除自身

parent.removeChild(child) — 父级删除子元素

parent.replaceChild(newChild, oldChild) — 替换

element.innerHTML = "" — 清空所有子元素

遍历 DOM 树

element.parentElement — 父元素

element.children — 所有子元素（HTMLCollection）

element.firstElementChild — 第一个子元素

element.lastElementChild — 最后一个子元素

element.previousElementSibling — 前一个兄弟

element.nextElementSibling — 后一个兄弟

事件委托

如果有 100 个 li，每个都绑事件性能差：

改为父元素监听：

document.querySelector("ul").addEventListener("click", function(e) {

  if (e.target.tagName === "LI") {

    console.log("点了:", e.target.textContent);

  }

})

动态新增的 li 也自动有事件——这就是事件委托。

dataset 自定义数据

HTML 里用 data-* 属性存数据：

<li data-id="42" data-type="enemy">哥布林</li>

JS 读取：

let id = li.dataset.id → "42"

let type = li.dataset.type → "enemy"

非常适合事件委托时获取相关数据。

classList 操作

element.classList.add("类名")

element.classList.remove("类名")

element.classList.toggle("类名") — 有则删无则加

element.classList.contains("类名") — 检查是否有

代替直接操作 className，避免了覆盖其他 class。

总结

  • createElement + appendChild 动态添加元素
  • remove() / removeChild() 删除
  • parentElement / children / siblings 遍历 DOM
  • 事件委托 = 父元素监听，e.target 判断子元素
  • dataset 存取 data-* 属性
  • classList 增删改查 CSS 类
