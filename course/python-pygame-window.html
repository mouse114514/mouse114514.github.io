Pygame 创建游戏窗口

第一个图形化程序

安装 Pygame

打开终端（Win+R → cmd）：

pip install pygame

等下载完成后测试：

python -c "import pygame; print(pygame.ver)"

如果显示版本号说明安装成功。

如果报错 "pip 不是命令"，重新运行 Python 安装程序，勾选 "Add Python to PATH"。

创建窗口

完整的 Pygame 窗口程序：

import pygame

pygame.init()

screen = pygame.display.set_mode((800, 600))

pygame.display.set_caption("我的游戏")

while True:

    for event in pygame.event.get():

        if event.type == pygame.QUIT:

            exit()

    pygame.display.update()

逐行解释

  • import pygame — 导入 Pygame 库
  • pygame.init() — 初始化所有 Pygame 模块
  • set_mode((800,600)) — 创建 800×600 像素的窗口
  • set_caption — 设置窗口标题
  • while True — 游戏主循环（每帧执行一次）
  • event.get() — 获取所有事件（按键、点击、关闭等）
  • pygame.QUIT — 用户点×关闭窗口的事件
  • display.update() — 刷新画面

设置背景颜色

在循环里加这句：

screen.fill((100, 150, 200))

RGB 颜色：(红, 绿, 蓝)，每个值 0-255。

例子：

  • (0, 0, 0) = 黑色
  • (255, 255, 255) = 白色
  • (100, 200, 100) = 草绿色

帧率控制 (Clock)

不加帧率控制游戏会跑得飞快，加个时钟：

clock = pygame.time.Clock() ← 在初始化部分

在主循环末尾加：

clock.tick(60) ← 限制每秒 60 帧

60 FPS 是标准的游戏帧率。tick(60) 会让循环每秒钟最多运行 60 次。

画一个矩形

在循环里加：

pygame.draw.rect(screen, (255,0,0), (100, 100, 80, 60))

  • screen — 画到哪个表面
  • (255,0,0) — 红色
  • (100, 100, 80, 60) — (x, y, 宽, 高)

画一个圆形

pygame.draw.circle(screen, (0,255,0), (400, 300), 50)

  • (0,255,0) — 绿色
  • (400, 300) — 圆心坐标
  • 50 — 半径（像素）

还有 ellipse（椭圆）、line（线条）、polygon（多边形）等。

总结

  • pip install pygame 安装库
  • pygame.init() 初始化，set_mode() 创建窗口
  • 主循环 while True 持续更新画面
  • event.get() 检测用户操作
  • screen.fill() 设置背景色
  • clock.tick(60) 锁定 60 帧
  • draw.rect() / draw.circle() 画图形
