GDScript 入门

让节点动起来

GDScript 是什么？

GDScript 是Godot 自带的脚本语言，语法像 Python，专门为游戏开发设计、/p>

  • 给节点添加脚有ↀ控制这个节点的行一/li>
  • 语法简洁，没有复杂的类型声是/li>
  • 和Godot 引擎深度集成，可以直接操作节点/li>
在场景树里选中节点 ↀ右键 ↀAttach Script ↀ就能给这个节点写代码、/div>

第一个脚有/h2>

给根节点挂一个脚本，Godot 自动生成基本结构！/p>

extends Node2D ↀ继承自什么节点类垀/p>

func _ready(): ↀ场景加载时自动执行/p>

func _process(delta): ↀ每帧循环执行

试一试：在_ready() 里写 print("Hello Godot")，运行后看底都Output 面板、/div>

变量

变量用来存数据：

var speed = 200 ↀ定义变量 speed，初始倀200

var player_name = "Alice" ↀ字符串用双引参/p>

var hp = 100 ↀ整数

变量可以在脚本顶部定义，也可以在函数里定义、/p>

GDScript 不用写变量类型，自动推断。写惯了 Java/C++ 会觉得特别爽、/div>

让节点移力/h2>

实现 WASD 控制角色移动！/p>

extends CharacterBody2D

var speed = 300

func _physics_process(delta):

   var dir = Vector2.ZERO

   if Input.is_action_pressed("ui_right"): dir.x += 1

   if Input.is_action_pressed("ui_left"): dir.x -= 1

   velocity = dir * speed

   move_and_slide()

信号（Signal！/h2>

信号是Godot 的事件广播"机制——一个节点发出信号，其他节点收到通知、/p>

  • 一个按钮被点击 ↀ发出 pressed 信号
  • 两个物体碰撞 ↀ发出 body_entered 信号
  • 计时器倒计时结来ↀ发出 timeout 信号
选中节点 ↀ右侧 Node 标签 ↀ信号列表 ↀ双击连接信号 ↀ选择接收方法、/div>

获取其他节点

脚本里怎么操控其他节点！/p>

$NodeName ↀ获取子节点（相对路径！/p>

$Path/To/Node ↀ多层级路得/p>

get_node("../Sibling") ↀ获取兄弟节点

示例！code>$Label.text = "得分: 100" ↀ修改 Label 的显示文字/p>

总结

  • GDScript = Godot 的脚本语言，语法像 Python
  • _ready() 初始化，_process(delta) 每帧更新
  • var 定义变量，Vector2 表示 2D 坐标/方向
  • 信号 = 事件广播机制，节点之间通信
  • $节点名获取子节点引用/li>
