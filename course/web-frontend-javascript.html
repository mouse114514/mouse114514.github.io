JavaScript 入门

让网页动起来

JavaScript 是什么？

JavaScript（简称 JS）是浏览器的编程语言。

  • HTML 定义内容
  • CSS 定义样式
  • JavaScript 定义行为
点击按钮弹出提示、图片轮播、表单验证、页面动态加载——都是 JS 做的。

引入 JS

在 HTML 里写 JS：

<script>

  alert("你好！");

</script>

或者引用外部文件：

<script src="script.js"></script>

<script> 标签通常放在 </body> 之前，这样 HTML 先加载完再执行 JS。

变量和输出

let name = "张三" ← 定义变量

const pi = 3.14 ← 常量（不能改）

console.log(name) ← 在开发者工具控制台输出

alert(name) ← 弹出提示框

document.write(name) ← 写入页面

操作 DOM

DOM = 浏览器把 HTML 转换成的"对象树"。

选中元素：

let btn = document.querySelector("#myButton")

let title = document.querySelector("h1")

修改内容：

title.textContent = "新标题"

title.style.color = "red"

事件监听

让按钮点击后执行代码：

let btn = document.querySelector("button")

btn.addEventListener("click", function() {

  alert("按钮被点了！")

})

常见事件：click（点击）、mouseover（悬停）、keydown（按键）、submit（提交）

函数

把代码打包复用：

function add(a, b) {

  return a + b

}

let result = add(3, 5) → result = 8

函数是 JS 最基础的组织代码方式。一个函数做一件事，名字要清楚。

总结

  • JS = 浏览器的编程语言，给网页加交互
  • let 定义变量，const 定义常量
  • querySelector() 选中元素，textContent 改内容
  • addEventListener 绑定事件（如 click）
  • function 定义函数，return 返回值
