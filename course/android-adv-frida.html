Frida 入门

动态插桩，无需重启

Frida 是什么？

Frida 是一一strong>动态插桩框析/strong>——运行中注入 JavaScript 代码分App 进程、/p>

  • 不需要重名App 就能 Hook
  • 不需要Root（部分功能需要）
  • 内JavaScript 就能 Hook Java 方法
  • 电脑端控制，手机端运行/li>
Frida 是目前安卓逆向最流行的Hook 工具，没有之一、/div>

安装 Frida

电脑端（PC）：

pip install frida-tools

手机端（Android）：

  1. GitHub 下载 frida-server 对应版本/架构
  2. adb push frida-server /data/local/tmp/
  3. adb shell chmod 755 /data/local/tmp/frida-server
  4. adb shell /data/local/tmp/frida-server &

基础 Hook 脚本

创建 hook.js！/p>

Java.perform(function() {

  var Main = Java.use("com.example.MainActivity");

  Main.isPaid.implementation = function() {

    console.log("isPaid called!");

    return true;

  };

});

运行！code>frida -U com.example.app -l hook.js

Frida 常用命令

  • frida-ps -U —列出 USB 设备上运行的进程
  • frida -U 进程名-l script.js —附加到运行中的进程/li>
  • frida -U -f com.example.app -l script.js --no-pause —启动 App 并注入/li>
  • frida -U 进程名/code> —进入 REPL 交互模式

Hook 带参数的方法

钩取带参数的方法！/p>

var Cls = Java.use("com.example.Utils");

Cls.encrypt.overload("[B", "java.lang.String").implementation = function(data, key) {

  console.log("encrypt called!");

  console.log("data:", bytesToString(data));

  console.log("key:", key);

  var ret = this.encrypt(data, key);

  return ret;

}

修改函数返回倀/h2>

常见场景：修改付费验证返回倀/p>

var Pay = Java.use("com.example.PayManager");

Pay.isVip.implementation = function() {

  return true;

}

Pay.getVipLevel.implementation = function() {

  return 3;

}

总结

  • Frida = 动态插桩，JS 脚本控制
  • frida-server 跑在手机上，frida-tools 跑在 PC 一/li>
  • Java.use() 获取类，implementation = 替换方法
  • overload() 处理同名不同参数的方法/li>
  • 常用场景：修改返回值、打印参数和调用校/li>
