音效与特效

让游戏更好听更好看

AudioStreamPlayer

播放音效的最基本节点。
拖入一个 .mp3 或 .ogg 文件到 Stream 属性。

代码控制：

$AudioStreamPlayer.play() ← 播放

$AudioStreamPlayer.stop() ← 停止

$AudioStreamPlayer.pitch_scale = 1.5 ← 变速变调

$AudioStreamPlayer.volume_db = -10 ← 音量（分贝）

音频文件格式

  • .mp3 — 压缩率高，适合音乐
  • .ogg — 开源格式，Godot 原生支持
  • .wav — 无损，适合短音效
短音效（开枪、跳跃）用 .wav，长背景音乐用 .ogg。

AudioStreamPlayer2D

2D 空间音效——声源在游戏世界里，有立体感：

  • 距离越远声音越小
  • 在左边播放 → 左声道响
  • 设置 Max Distance 控制可听范围

适合脚步声、枪声、环境音效。

粒子系统 GPUParticles2D

粒子效果：火焰、烟雾、爆炸、星光。

  • 创建 GPUParticles2D 节点
  • Amount — 粒子数量
  • Lifetime — 每个粒子存在秒数
  • 速度 / 方向 / 旋转 — 粒子运动参数
  • Material → ParticleProcessMaterial — 颜色渐变

粒子发射控制

$GPUParticles2D.emitting = true ← 开始发射

$GPUParticles2D.emitting = false ← 停止发射

$GPUParticles2D.one_shot = true ← 只喷一次（爆炸效果）

爆炸效果：one_shot = true → 调用 emitting = true → 等粒子全部消失后自动停止。

Tween 过渡动画

Tween 让属性平滑变化：

var tween = create_tween()

tween.tween_property($Sprite, "modulate:a", 0, 0.5) ← 渐隐

tween.tween_property($Sprite, "scale", Vector2(2,2), 1.0) ← 放大

tween.tween_property($Node2D, "position", Vector2(100,0), 0.3) ← 滑动

总结

  • AudioStreamPlayer 播放音效，play()/stop()/pitch_scale
  • AudioStreamPlayer2D 实现空间音效（左/右/远/近）
  • GPUParticles2D 做火焰/爆炸等粒子效果
  • Tween 创建平滑过渡动画（移动/缩放/渐隐）
