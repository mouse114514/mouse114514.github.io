第四课

软件安装与卸载

给电脑装你想要的程序

什么是软件？

软件 就是安装在电脑上的程序，用来完成特定的任务。

  • 用浏览器上网（Chrome、Edge）
  • 用办公软件写文档（Office、WPS）
  • 用播放器看视频（PotPlayer、VLC）
  • 用聊天软件交流（微信、QQ）
💡 没有软件的电脑只是一台"裸机"，什么也干不了。

如何获取软件？

  • 官网下载 —— 最安全的方式，直接在搜索引擎搜软件名+官网
  • 微软应用商店 —— 系统自带的商店，安全方便
  • 软件管家/管理工具 —— 如腾讯软件管家（小心捆绑）
⚠️ 不要到乱七八糟的下载站下载！很多会捆绑流氓软件。

安装软件的一般步骤

  • 双击下载的安装文件（通常是 .exe 或 .msi）
  • 如果有安全提示，点"是"或"允许"
  • 选择安装语言（一般默认中文）
  • 选择安装位置（一般默认 C 盘即可）
  • 一路点"下一步"或"安装"
  • 安装完成后点"完成"
💡 安装时注意取消勾选捆绑的额外软件！

安装时要注意什么？

很多免费软件安装时会捆绑其他软件，安装时一定要看仔细：

  • 每步都看清楚了再点"下一步"
  • 遇到"推荐安装"/"默认安装"的勾选框，不需要就取消
  • 遇到"修改浏览器主页"的勾选，一定要取消
💡 慢一点、看仔细，比装了一堆垃圾软件再删省事得多。

如何卸载软件

方法一（推荐）：设置 → 应用 → 应用和功能，找到要删的软件点"卸载"

方法二：控制面板 → 程序和功能（旧版系统）

方法三：在某些软件自己的安装目录里找 uninstall.exe

⚠️ 不要直接删软件的文件夹！那样删不干净还会留下垃圾。

常用软件推荐

  • 浏览器：Chrome / Edge / Firefox
  • 办公：WPS Office（免费）/ LibreOffice（免费开源）
  • 压缩：7-Zip（免费无广告）
  • 播放器：PotPlayer / VLC
  • 截图：Snipaste / 微信截图
  • 输入法：搜狗 / 微软拼音（系统自带）

总结

  • 从官网或商店下载软件，不要用野鸡下载站
  • 安装时看清楚每一步，取消捆绑软件的勾选
  • 卸载走系统设置，不要直接删文件夹
  • 常用软件选口碑好的，免费够用了
