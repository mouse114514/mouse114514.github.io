Python 基础语法

编程的第一行代码/div>

Hello World

打开上一课装好的 Thonny 戏IDLE，输入：

print("Hello World")

按回软ↀ屏幕上显示Hello World

print() 是Python 的说话"函数，括号里写什么，屏幕上就显示什么、/div>

变量

变量用来存数据：

name = "小明" ↀ字符一/p>

age = 12 ↀ整数

score = 95.5 ↀ小数（浮点数！/p>

is_alive = True ↀ布尔倀/p>

然后用print 打印！code>print(name) ↀ显示"小明"

输入

让用户输入文字：

name = input("你叫什么名字？")

print("你好！ + name)

input() 会让程序停下来等用户输入，输完按回车才继续、/p>

input() 返回的永远是字符串。如果输入了数字要用 int() 转换！code>age = int(input("年龄！))

if 判断

根据条件做不同的事：

score = 85

if score >= 60:

    print("及格了)

else:

    print("不及校)

冒号！）后面用 4 个空格缩进表示属于这个条件"的代码。缩进是 Python 的语法规则！

for 循环

重复做事用循环：

for i in range(5):

    print("第, i, "欀)

输出：第 0 欀第1 次…第 4 欀/p>

range(5) 生成 0 分4 一入5 个数字、/p>

Python 代0 开始计数，不是 1。记住了很多奇怪的问题就不会出现、/div>

列表（List！/h2>

列表存一堆东西：

enemies = ["slime", "goblin", "dragon"]

print(enemies[0]) ↀslime

enemies.append("boss") ↀ添加元素

print(len(enemies)) ↀ4 一/p>

用for 循环遍历列表！code>for e in enemies: print(e)

总结

  • print() 输出，input() 输入
  • 变量不用声明类型，直接赋倀/li>
  • if/else 做条件判断，注意冒号和缩进/li>
  • for 循环 + range() 做重复操但/li>
  • 列表 [] 存多个元素，代0 开始索开/li>
