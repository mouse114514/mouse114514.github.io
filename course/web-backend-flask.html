Flask 入门

用Python 写第一个后站/div>

Flask 是什么？

Flask 是一一Python 的strong>Web 框架——帮你快速搭建后端服务器、/p>

  • 轻量、简单、适合新手
  • 一一.py 文件就能跑起一个网站后站/li>
  • 处理 HTTP 请求、返回响序/li>
框架 = 半成品，你只需要写核心逻辑，框架处理底层的东西（路由、请求解析、响应封装）、/div>

安装 Flask

pip install flask

验证安装！/p>

python -c "import flask; print(flask.__version__)"

能显示版本就成功了、/p>

Hello World

新建 app.py！/p>

from flask import Flask

app = Flask(__name__)

@app.route("/")

def home():

    return "Hello World"

if __name__ == "__main__":

    app.run(debug=True)

运行！code>python app.py ↀ浏览器访问http://127.0.0.1:5000

路由（Route！/h2>

不同的URL 路径 ↀ不同的处理函数：

@app.route("/") ↀ首页

@app.route("/about") ↀ关于页面

@app.route("/user/<name>") ↀ动态路得/p>

示例！/p>

def user(name):

    return f"你好，{name}"

返回 JSON

后端经常返回 JSON 数据给前端：

from flask import jsonify

@app.route("/api/data")

def get_data():

    return jsonify({"name": "张三", "score": 95})

浏览器访问/api/data ↀ看到 JSON 格式的数据、/p>

总结

  • Flask 是Python 的轻量级 Web 框架
  • pip install flask 一键安装/li>
  • @app.route() 定义 URL 路由
  • return 字符一ↀ网页；jsonify() ↀJSON 数据
  • methods 参数控制 GET / POST
