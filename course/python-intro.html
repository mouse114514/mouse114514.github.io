最适合新手的编程语言

Python 是什么？

Python 是一私strong>编程语言——你用它"告诉电脑做什之、/p>

  • 语法简洁，接近英语！strong>很适合新手入门

Python 能做什么？

下载和安装Python

  • 打开官网！strong>python.org
  • 鼠标移到 Downloads ↀ点Windows（系统会自动推荐最新版！/li>
  • 下载 .exe 安装文件
  • 运行安装程序 ↀ一定要勾通"Add Python to PATH"（这步很重要！）
  • 点Install Now ↀ等安装完戏/li>

验证安装成功

  • 持Win + R ↀ输入 cmd ↀ回车
  • 在黑窗口里输入python --version
  • 如果显示 Python 3.x.x，说明安装成功了
如果提示"python 不是内部或外部命代，说明安装时没勾"Add Python to PATH"，重新装一次再勾上、/div>

写你的第一行Python 代码

方法一：在命令行输入python 回车 ↀ进入交互模式

  • 输入 print("Hello World") ↀ回车
  • 屏幕上就会显示Hello World
  • 输入 exit() 退出/li>

方法二：用编辑器内.py 文件

  • 新建一个记事本，写一print("Hello World")
  • 保存一hello.py（不是.txt！）
  • 在命令行运行 python hello.py

用Pygame 做游戏/h2>

Pygame 是Python 最流行的2D 游戏库。安装很简单：

  • 在命令行输入！code>pip install pygame
  • 等着下载完成
  • 之后就能在你的Python 代码释import pygame 来用
pip 是Python 的包管理器"，用来安装别人写好的库。以后装任何 Python 库都用它、/div>
